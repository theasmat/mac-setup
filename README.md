# 🍏 macOS Developer Machine Setup

An interactive, transparent setup script designed to configure fresh macOS installations for software engineering. 

Rather than executing blind bulk installations, the script prompts a user for every optimization individually. The terminal displays the exact operational effect before any system modification occurs, ensuring a developer retains full control over the system environment.

## 🚀 Quick Start

A developer can copy and paste the following command into the macOS Terminal to execute the script directly from GitHub. Standard input remains active so interactive prompts function correctly.

```bash
bash -c "$(curl -fsSL [https://raw.githubusercontent.com/theasmat/mac-setup/main/setup.sh](https://raw.githubusercontent.com/theasmat/mac-setup/main/setup.sh))"
